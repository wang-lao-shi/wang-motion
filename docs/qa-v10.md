## v10.1 背景音乐（2026-11-14）

| 项 | 结果 |
|---|---|
| CLI 回归：100 模板 × 3 时刻（不加音乐）v9 vs v10.1 | 300/300 AE 0 |
| 网页回归：v9 vs v10.1 index.html，同 300 张 | 300/300 AE 0 |
| CLI `render --audio`（5 s 音乐，9 s 视频） | 音轨 9.00 s = 视频 9.00 s（循环，不再截短）；开头 -39 dB → 中段 -24 dB → 结尾 -48 dB（淡入 / 淡出生效） |
| CLI `--audio-fit --audio-offset 2`（20 s 音乐） | 自动 4 圈，视频 24 s，音轨 24 s |
| 网页 App：🎵 按钮（舞台 + 演示）、导出面板一行、上传、播放 / 暂停 / M 静音 / 预览入场从头、设置记忆、GIF 提示、长度跟音乐圈数 | 13/13 |
| 网页导出 MP4（720p24，入场 + 1 圈） | 视频 7.917 s / 音轨 7.920 s；音量 0.7、淡入淡出生效。沙箱 Chromium 无 AAC 编码 → Opus，完成提示有说明 |
| 网页导出 ZIP | 含 mp4（带音轨）+ audio/原文件；spec.json 有 audio{} |
| 网页导出交互网页 | 音乐以 data:audio 嵌入 |
| 播放器：默认出声 / 时钟同步 / 拖进度对齐 / 4× 时音乐仍 1× / M 静音 | 全过（允许自动播放） |
| 播放器：浏览器拦截有声自动播放 | 画面照常、提示「点击任意位置开启声音」，第一次点击后出声，其余同上全过 |

修复：播放器开音乐时按真实时间走钟（v10 每帧上限 0.1 s，低帧率时音乐会被拉回）；舞台暂停 / 静音改为立即生效（不等 rAF）。

待真机：Windows / Mac Chrome、Edge 的 AAC 音轨；PowerPoint 播放带音轨 MP4；Safari 双击 HTML 的首次点击出声。
