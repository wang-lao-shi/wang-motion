# 素材张数（容量）

每个模板能展示的「不同图片」数量不同。下表由真实引擎实测（一个循环内采样 24 帧，统计用到的素材序号）：

- **用得上**：这个模板最多能展示几张不同的图。素材少于它会循环重复；多于它，排在后面的图不会出现（按 `--media-dir` 文件名的自然顺序取前 N 张）。
- **同屏约**：同一时刻大约能看到几张（含透过缝隙看到的背面卡片）。
- 想用更多的图：把素材分批，每批 N 张各渲染一条。
- `card-globe`、`orbit-globe` 默认按经度「一列一张」；加 `--param mediaSpread=unique` 后每张卡依次取下一张图，球面能铺满更多不同的图。
